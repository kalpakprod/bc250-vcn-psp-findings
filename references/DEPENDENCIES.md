# Reproduction dependencies

This is an archival research handoff, not a turnkey executable kit. No external dependency was installed and no firmware built or hardware operated to prepare it.

## Unavailable local inputs

Original BIOS/ROM samples, PSP/SMU extracted bodies, staged firmware, boardview originals, complete vendor code listings and private board captures are not bundled. Their relative paths, sizes and existing identity/provenance information are retained in the catalog and authored reports where available. Use an authorized matching input, not a similarly named ROM.

Existing tools may require the original workspace layout, EDK II/Pico SDK, firmware analyzers or non-bundled local modules. In the public layout, code is under `code/`, documentation under `research/`, and captures under `evidence/`. A historical absolute/local path is not expected to work on your machine. Do not run an old build/flash/probe command solely because it was preserved here.

[Unavailable original Markdown targets](UNAVAILABLE-LINKS.json) records historical source links which could not be bundled. Such links in the released Markdown were redirected to this explanation; their original targets remain in that record. This fixes public navigation without pretending that withheld inputs were supplied. Inline code paths and shell/Python runtime dependencies were not silently rewritten to claim portability.

No codec functionality, hardware first-bit timing, no-solder wiring, board revision/voltage or current electrical ownership has been verified by this packaging operation.
