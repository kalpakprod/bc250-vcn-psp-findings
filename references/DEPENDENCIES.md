# Inputs needed to reproduce the work

Some tools need files and a workspace layout that this archive does not supply. No external dependency was installed, firmware built or hardware operated to prepare the original collection.

## Unavailable local inputs

Original BIOS/ROM samples, extracted PSP/SMU bodies, staged firmware, original boardviews, complete vendor code listings and private board captures are not bundled. The catalog and authored reports retain their relative paths, sizes and recorded identity/provenance information where available. Use an authorized matching input. A ROM with a similar name is not a substitute.

Tools may need the original workspace layout, EDK II/Pico SDK, firmware analyzers or local modules that are not included. Here, code is under `code/`, documentation under `research/`, and captures under `evidence/`. Historical absolute or local paths will not necessarily work on another machine. Keeping an old build, flash or probe command in the archive is not a reason to run it.

[Unavailable original Markdown targets](UNAVAILABLE-LINKS.json) lists historical links whose targets could not be included. Those links now point to this explanation, and the record retains their original targets. The navigation works without suggesting that the missing inputs were supplied. Inline code paths and shell/Python runtime dependencies were not silently rewritten to make the tools appear portable.

Preparing this archive did not verify codec functionality, hardware first-bit timing, no-solder wiring, board revision or voltage, or current electrical ownership.
