# BC-250 hardware-baseline matrix: saved evidence vs. present state

Date: 2026-09-21 (Asia/Almaty). This is a read-only integration of the six completed topic ledgers and the subsequently delivered board-photo ledger. No board access, programmer transaction, ROM/NVRAM/register write, voltage probe, external search, or new benchmark was performed.

## Executive conclusion

The repository supports a **last-saved configuration**, not a complete statement of the board's present physical or runtime state. The latest saved programmer readback identified in the project is the 2026-09-19 W11-labelled binary, hash `3c50bc9a65194b75ca805e6ed31c5778369de1fe8eca4600f44e15fae3b40fc3`. Its stored NVRAM has `Memory Clock Speed=0x24` (static HII label `1800MHz`), `UclkDiv1M0=0x01` (`Enabled`), `Memory P-state=Auto`, `FCLK_DPM=Auto`, and manual DF override `1420`. These are saved request bytes only: there is no current readback, boot-to-W11 identity, physical MCLK/UCLK/FCLK measurement, training result, or current-board performance/voltage measurement.

`BC250_5.00_clv.bin` (`ea578104…ca4cb8`) is a RetroWeb community donor, not the board's 2026-09-19 readback. The W11 readback is distinct from pristine CLV and is itself only the newest **preserved** chip snapshot; the W11-specific binary has no same-date flashrom stdout log or capture manifest in the reviewed inventory. Project state records that the board was unreachable at the 2026-09-20 check, so present chip contents remain unknown.
