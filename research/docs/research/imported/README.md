# Исторические импортированные исследования

Файлы этой папки — снимки прежней работы и копии документов, а не действующие инструкции по прошивке, SMU-записям или подключению платы. Имя `SAFE` и успешный старый лог не подтверждают безопасность сегодня.

- [Разбор 11 документов `bc250-bios`](../2026-09-27-imported-bios-docs-disposition.md): где уже есть побайтные копии, какие два текста уникальны и почему они помечены историческими.
- [Текущие пробелы автономной прошивки](../2026-09-27-autonomous-firmware-gaps.md) и [границы OC-доказательств](../2026-09-27-clock-oc-status-audit.md): актуальные ограничения утверждений.
- Исходные файлы без изменений и SHA-256 сохраняются в `archives/imported/`; маршрут каждого файла указан в `docs/import-catalog.md` и журналах аудита.

Ничего из этой папки не запускать на плате по одному лишь тексту документа.
