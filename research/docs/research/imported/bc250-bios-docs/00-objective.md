# Цель

## Формулировка

- Полный реверс-инжиниринг BIOS платы AMD BC-250 до уровня предсказуемой сборки.
- Критерий готовности: запрос «напиши свой BIOS с патчем X» завершается собранным образом и предсказанием поведения за максимум две проверочные итерации.

## Объём

- Структура образа: SPI-карта, PSP-каталог, блобы политик, FV/FFS, APCB, NVRAM.
- PSP-механика: загрузка, верификация, применение политик, реестр групп, интерпретаторы.
- Разблокировки: 8C16T CPU, вычислительные блоки GPU (CU, VCN).
- Разгон: тайминги памяти, причина несброса планки, лимиты (PPT, TDC, EDC), тактовые домены.
- Оболочка: декодер IFR, скрытые пункты setup, вариант современной оболочки (ASUS/Acer-класс).
- Эксплуатация: Windows-совместимость, поверхность детекции античитов, PSP-аттестация.

## Ограничения

- Аппаратные проверки выполняет тестер; порядок прошивки: D3-C → D3-B2 → D3-A.
- Неподписанные образы не прошиваются без статического анализа риска применительно к путям применения.
- Внешние воздействия (публикации, коммиты) выполняются только по явному запросу.
