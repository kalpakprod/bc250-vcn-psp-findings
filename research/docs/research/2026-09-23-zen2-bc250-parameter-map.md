## Что действительно говорит документация

AMD2.9 в разделе RYZEN3000-SERIES CPUS — MEMORY AND FABRIC OVERCLOCKING описывает независимый разгон Infinity Fabric и Memory clock. Для типичного разгона до1866MHz называет связь fabric/memory1:1 наиболее эффективной. Это ориентир для Ryzen3000 DDR4, не гарантированный предел и не рецепт BC250. Там же DDR4-3600 соответствует1800MHz memory clock.

Практическое DDR4-руководство рекомендует проверять совпадение FCLK/UCLK/MCLK, предупреждает о штрафе рассинхронизации и предлагает после выбора частоты настраивать тайминги. В тексте есть слишком общее связывание рассинхронизации FCLK с половинным UCLK, поэтому этот абзац не принимается как универсальное правило делителя. Реальный режим определяется отдельно.

| Фактор                  | Что проверять на BC250                                                   | Что не переносить автоматически                                            |
| ----------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| MCLK/UCLK/FCLK          | Физические домены, делители, выбранный режим и применение команды        | DDR4 MT/s ÷2 как формулу для любых GDDR6 показаний                         |
| Fabric и Memory P-state | Переключение режимов и его возможный вклад в разброс задержек            | Настройки EPYC или desktop power states без своего потребителя             |
| Тайминги                | Реальные применяемые Tcl и поля контроллера, обучение памяти             | DDR4 B-die таблицы и вторичные тайминги по одному названию                 |
| SoC                     | Путь управления VDDCR_SOC, единицы, измерение                            | raw VDD offset как абсолютное SoC, VDDG/VDDP рекомендации для другой платы |
| Нагрузка и измерение    | Рабочий набор больше кэша, одинаковые CPU/GPU условия, повторные прогоны | Обещание Ryzen-подобного числа ns по идентичности ядра Zen2                |

Предел SoC1.15В — требование пользователя, не доказанная безопасная норма. Более высокое напряжение не обязано улучшать стабильность. До установления setter нельзя выполнять требуемый первый шаг разгона. Это не блокирует офлайн-анализ частот.

## Полученный практический паспорт

10 полей сведены в evidence/firmware-audit/20260923-oc-parameter-map/parameter-map.md и parameter-map.json. Проверены байты IFR и команды сериализации на точном модуле, плюс сохранённые значения clean ROM. Значения1800MHz/DF1420 — запросы в ROM, не измерения платы и не выбранный профиль.

Рабочий порядок остаётся: измерительный baseline → подтверждённый SoC первым → частоты/делители при исходных таймингах → тайминги → режимы питания. Численный профиль пока не назначен, поскольку фактическое применение не установлено.

## Новая существенная находка: прежние исправления token-ID были неверны

Отчёты2026-09-20 ошибочно сопоставляли загрузку значения со следующим ID записи. В serializer ID записывается ДО загрузки значения, затем pointer увеличивается. Исполнение неизменённого native serializer с разными маркерами снимает неоднозначность соседних полей:

- Setup+6A2 →1330, +6A3(FCLK_DPM) →1331, +6A4 →1332.
- Setup+36C →123B, +36D(Memory P-state) →123C, +36E →123D.

Baseline: маркеры A1/B2/C3 и31/42/53. Modified: C3/A1/B2 и53/31/42. Restored: исходные маркеры. Три процесса exit0, stderr пуст, все выходы следуют своим входам. Модули извлечены из исполняемых стендов и побайтно равны исходным. ROM не изменён. Это не firmware rollback и не аппаратное испытание.

Команда: python evidence/firmware-audit/20260923-oc-parameter-map/discriminator/verify.py

Результат меняет следующий поиск: для FCLK_DPM использовать1331, для Memory P-state123C, не1332/123D. Старые отрицательные поиски неверного ID не отвечают на вопрос о целевом поле. Не повторять весь старый поиск: сначала проверить, какие исходные caller-артефакты уже покрывают правильные ID.

## Незавершённое

A3: downstream clock/SoC actuator остаётся открыт. STATIC-PASS нового разгонного образа и HARDWARE-PASS отсутствуют. Цель не завершена.
