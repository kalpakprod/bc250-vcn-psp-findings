## 1. J5 — UART (последовательная консоль)

**Разъём:** 1×4P, шаг 1.0 мм, `HD_1X4P_100_PINREX_LFA`

```
J5 (вид сверху, пин 1 = ближний к маркировке)

  [1]  [2]  [3]  [4]
```

| J5 пин | Сигнал   | Назначение            | Подключать к CH347T |
| ------ | -------- | --------------------- | ------------------- |
| 1      | +3.3V_SB | Питание (standby)     | **НЕ ПОДКЛЮЧАТЬ**   |
| 2      | GND      | Земля                 | GND                 |
| 3      | U_TX     | Выход UART (от BC250) | RXD (вход CH347)    |
| 4      | U_RX     | Вход UART (к BC250)   | TXD (выход CH347)   |

### DuPont-подключение UART (3 провода):

```
CH347T (Mode 1: SPI+UART)          J5 на плате BC-250
─────────────────────────           ──────────────────
  GND  ──────────────────────────── pin 2 (GND)
  RXD  ──────────────────────────── pin 3 (U_TX)
  TXD  ──────────────────────────── pin 4 (U_RX)

  НЕ подключай pin 1 (+3.3V_SB) — CH347 питается от USB.
  Перекрёстное: TX платы → RX адаптера, и наоборот.
```

**Параметры:** 115200 8N1. Команда: `screen /dev/ttyACM0 115200`

**Физика:** пины J5 с шагом 1.0 мм — стандартные DuPont 2.54 мм НЕ подойдут.
Нужны либо:

- Провода с коннектором 1.0 мм (JST SH / Molex Picoblade)
- Либо припаять тонкие провода напрямую к площадкам

## 2. J4004 — SPI (программатор / TOCTOU)

**Разъём:** 2×4P, шаг 2.54 мм, `HEADER 2X4P S/T 2.54MM` — стандартные DuPont подходят!

```
J4004 (вид сверху, ключ/маркировка слева)

  Верхний ряд:  [1]  [3]  [5]  [7]
  Нижний ряд:   [2]  [4]  [6]  [8]
```

| J4004 пин | Сигнал        | SPI функция | SOIC-8 пин флешки |
| --------- | ------------- | ----------- | ----------------- |
| 1         | +3.3V_SB      | VCC         | 8                 |
| 2         | GND           | GND         | 4                 |
| 3         | SB_RSPI_CS#   | CS#         | 1                 |
| 4         | SB_SPI_CLK    | CLK/SCLK    | 6                 |
| 5         | SB_SPI_DI     | MOSI (DI)   | 2                 |
| 6         | SB_SPI_DO     | MISO (DO)   | 5                 |
| 7         | (не задокум.) | —           | —                 |
| 8         | PROGRAM#      | WP control  | —                 |

### DuPont-подключение SPI к CH347T (6 проводов):

```
CH347T SPI                          J4004 на плате BC-250
──────────                          ─────────────────────
  VCC (3.3V) ────────────────────── pin 1 (+3.3V_SB)
  GND  ──────────────────────────── pin 2 (GND)
  CS#  ──────────────────────────── pin 3 (SB_RSPI_CS#)
  SCK  ──────────────────────────── pin 4 (SB_SPI_CLK)
  MOSI ──────────────────────────── pin 5 (SB_SPI_DI)
  MISO ──────────────────────────── pin 6 (SB_SPI_DO)
```

**ВАЖНО:** Плата ДОЛЖНА быть полностью обесточена при SPI-прошивке через J4004.
+3.3V_SB — это standby-рельса, она живёт при подключённом БП даже когда плата выключена.
Отключи кабель питания от БП перед подключением программатора.

### Альтернатива: SOIC-8 клипса на чип BIOS_A1

Чип: **MXIC MX25L12872FM2I-10G** (128 Мбит = 16 МБ, 3V, SOP-8)

```
BIOS_A1 (SOP-8, вид сверху, точка = пин 1)

  ●[1] CS#      [8] VCC
   [2] DI/MOSI  [7] HOLD#
   [3] WP#      [6] CLK
   [4] GND      [5] DO/MISO
```

## 3. TPMS1 — LPC/POST debug

**Разъём:** 2×9P, шаг 2.00 мм — DuPont 2.54 мм НЕ подойдут, нужен 2.0 мм.

```
TPMS1 (вид сверху)

  Верхний:  [1]  [3]  [5]  [7]  [9]  [11] [13] [15] [17]
  Нижний:   [2]  [4]  [6]  [8]  [10] [12] [14] [16] [18]
```

| Пин | Сигнал    | Назначение         |
| --- | --------- | ------------------ |
| 1   | PCLK_S4   | LPC clock          |
| 2   | GND       | Земля              |
| 3   | LFRAME#   | LPC frame          |
| 4   | SMBCLK    | SMBus clock        |
| 5   | A_RST#    | Reset              |
| 6   | SMBDATA   | SMBus data         |
| 7   | LAD3      | LPC data bit 3     |
| 8   | LAD2      | LPC data bit 2     |
| 9   | +3.3V_RUN | Питание (run-time) |
| 10  | LAD1      | LPC data bit 1     |
| 11  | LAD0      | LPC data bit 0     |
| 12  | GND       | Земля              |
| 14  | LPC_PD#   | Power down         |
| 15  | +3.3V_SB  | Питание (standby)  |
| 16  | SERIRQ    | Serial IRQ         |
| 17  | GND       | Земля              |
| 18  | F_CLKRUN# | Clock run          |

Для POST-карты: подключить LAD0-3 (пины 11,10,8,7), LFRAME# (3), PCLK_S4 (1), GND (2/12/17).

## 4. TOCTOU Rig — Waveshare RP2350B-Plus-W → BC-250 SPI

Архитектура: Pico 2 сидит man-in-the-middle на линии MISO между PSP и флешкой.

### Распиновка SomnacinDumper PicoModchip (референс):

```
Pico GPIO  | Функция
-----------|---------------------------
GPIO 10    | SPI MOSI (вход, от PSP)
GPIO 12    | SPI CLK (вход, от PSP)
GPIO 13    | CS от материнки (вход)
GPIO 17    | CS к флеш-чипу (выход)
GPIO 18    | MISO (выход к PSP / вход от флешки)
GPIO 21    | Inject selector (внутренний)
GPIO 16    | Target reset (выход)
GPIO 4-9   | LPC bus (опционально, POST codes)
```

### Наша адаптация (single-flash, MISO substitution):

```
Waveshare RP2350B GPIO  | Подключение
------------------------|----------------------------------
GPIO 10                 | J4004 pin 5 (SB_SPI_DI / MOSI)
GPIO 12                 | J4004 pin 4 (SB_SPI_CLK)
GPIO 13                 | J4004 pin 3 (SB_RSPI_CS#)
GPIO 17                 | BIOS_A1 pin 1 (CS# — напрямую к чипу)
GPIO 18 (выход)         | К PSP MISO (разрыв дорожки BIOS_A1.5 → FCH)
GPIO 18 (вход, alt)     | От BIOS_A1 pin 5 (DO/MISO — чтение реальных данных)
GND                     | J4004 pin 2 (GND)
```

**Критический момент:** линия MISO (SB_SPI_DO) должна быть РАЗОРВАНА между
флеш-чипом и FCH/PSP. Pico читает MISO с чипа на один GPIO, выдаёт данные
(оригинальные или подменённые) на другой GPIO к PSP.

### Схема подключения TOCTOU:

```
                    PSP/FCH (на плате BC-250)
                    ┌─────────────────────┐
                    │  SCLK ──────────────┼──── J4004.4 ──┬── GPIO12 (Pico, вход)
                    │  MOSI ──────────────┼──── J4004.5 ──┬── GPIO10 (Pico, вход)
                    │  CS#  ──────────────┼──── J4004.3 ──┬── GPIO13 (Pico, вход)
                    │  MISO ◄─── [РАЗРЫВ] │               │
                    │    ▲                │               │
                    │    │                │               │
                    │    └── GPIO18out ◄──┼───────────────┤ Pico выход
                    └─────────────────────┘               │
                                                          │
                    BIOS_A1 (SPI flash)                   │
                    ┌─────────────────────┐               │
                    │  CS#  ◄─────────────┼── GPIO17 (Pico, выход)
                    │  CLK  ◄─────────────┼── (параллельно с SCLK)
                    │  DI   ◄─────────────┼── (параллельно с MOSI)
                    │  DO ────────────────┼── GPIO18in (Pico, вход)
                    └─────────────────────┘

Pico PIO логика:
  1. spi_trigger: ловит cmd 03 + адрес, сравнивает с target range
  2. spi_inject: если адрес в anchor window (0x9DB560..0x9DB6A0):
     - 1-е чтение: выдаёт оригинальные 320 байт из SRAM
     - 2-е чтение: пропускает данные с флешки (наши ключи)
  3. Для всех остальных адресов: пропускает MISO с флешки как есть
```

## 6. Минимальный набор для текущей сессии

### Вариант A: UART debug (3 провода, нужен 1.0мм коннектор)

```
CH347T RXD  →  J5 pin 3 (U_TX)
CH347T TXD  →  J5 pin 4 (U_RX)
CH347T GND  →  J5 pin 2 (GND)
```

### Вариант B: SPI flash через J4004 (6 DuPont проводов)

```
CH347T VCC  →  J4004 pin 1 (+3.3V_SB)
CH347T GND  →  J4004 pin 2 (GND)
CH347T CS   →  J4004 pin 3 (CS#)
CH347T SCK  →  J4004 pin 4 (CLK)
CH347T MOSI →  J4004 pin 5 (DI)
CH347T MISO →  J4004 pin 6 (DO)
```

### Вариант C: TOCTOU rig (Pico 2 + J4004 + разрыв MISO)

Требует: разрыв дорожки SB_SPI_DO между чипом и FCH,
либо снятие чипа и установка в сокет с перехватом MISO.
