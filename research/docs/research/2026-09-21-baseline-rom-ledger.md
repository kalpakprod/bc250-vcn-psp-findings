## Conclusion

The preserved ROM called `BC250_5.00_clv.bin` is a **RetroWeb community donor**, not the user's SPI capture and not the last-confirmed image read back from the user's board. The newest recorded postwrite image explicitly represented as a chip readback in the preserved set is `evidence/programmer/reads/20260919/postwrite-vcn-unlock-w11-v001.bin`, SHA-256 `3c50bc9a65194b75ca805e6ed31c5778369de1fe8eca4600f44e15fae3b40fc3`. It is byte-identical to the file named `candidates/BC250_5.00_clv_VcnUnlock_W9_v001.bin`, but differs from both the earlier actual W9 readback (`449475…`) and the original `5.00_clv` donor (`ea578…`). Therefore, the latest **confirmed-on-chip-at-capture** state is W11 / W9-labelled candidate bytes, a CLV-derived image—not pristine CLV. This is not a fresh statement of what is physically installed today: no post-2026-09-19 readback was found; project state says the board was unreachable at the 2026-09-20 check.
