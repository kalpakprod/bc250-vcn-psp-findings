## Objective

Build ONE unified BIOS image on the pinned 5.00-CLV base that, on first boot with
defaults loaded, requests 1:1:1 clocks and OC voltages, carries the 8-core unlock
driver set, passes structural validation + independent review, and ships with a
programmer flash gate (approval form, fresh dump, readback, rollback).

## In scope (staged ladder, ONE variable per stage)

1. S1 — 1:1:1 request defaults at H1330 (`+0x316=0x1A`, `+0x330=0x01`,
   `+0x703=0x01`, `+0x704=0x0532`; `+0x36D` per DF-help arbitration, default 0xFF
   unless review justifies 0x00). No voltage changes.
2. S2 — S1 + OC voltage defaults via the statically-traced fixed-voltage Setup path
   (VCORE/GFX/MEMIO enables+values+loadlines within IFR-declared shapes) and
   VDDCR_VDD offset ONLY if its consumer/rail/unit block closes; otherwise the
   offset stays 0 and is labelled request-only/unproven.
3. S3 — S2 + 8-core unlock driver set (0968a70c lineage: 187→193 FFS, DEPEX check
   incl. e1d5c3a7 intra-set note) + Setup-unhide class ONLY if statically closed;
   otherwise deferred with reason.
4. S4 — flash gate package: programmer procedure, exact-approval form, fresh x2 dump
   requirement, readback + rollback image, cold-boot checks.

## Out of scope / hard NO-GOs (from history, restated)

- SoC 1.15V as a BIOS setpoint: NO-GO (analog RT8237E, no software setpoint).
  1.15V stays a ceiling only.
- "Equal numbers = proven 1:1:1": REJECTED. Physical sync needs independent domain
  counters + crossing status + training proof on hardware (acceptance phase, not build).
- "Stored bytes = applied volts/clocks": REJECTED. Request-only labelling until
  hardware readback.
- Whole-FV graft, 4700S Frankenstein, PSP/APCB signed-region edits: excluded.
- pp_od `s`-path max-first: dead on 7.2.6-1.2 (peer EINVAL); `vc`-path retest is a
  separate live experiment, not part of this image.

## Acceptance criteria (per layer)

- BUILD: image boots the structural gate — size/hash recorded, FV/FFS/NVAR parse
  PASS, changed-range report vs base, df1400-only builder profile extended with
  unit tests that still reject unknown sync/voltage shapes, no PSP/`$PS1`/APCB
  signed-region deltas.
- REVIEW: independent reviewer (different model family if available) inspects diff,
  evidence, failure path; states scope + unrun checks. Incomplete review = not done.
- FLASH GATE (no flash without ALL): board identity + chip identity match, fresh x2
  programmer dumps with matching hashes, recovery image verified, operator exact
  approval text naming file+hash+target, readback+rollback plan. Flash itself is a
  separate explicit order.
- HARDWARE (after gated flash): POST+video, Setup shows requested defaults, NVRAM
  readback matches, training completes, independent clock/voltage measurement per
  the acceptance protocol. Sync/applied-volts claims ONLY from this layer.
