# bc250-bios

Полный реверс-инжиниринг BIOS платы AMD BC-250 (Cezanne APU, PSP RoT, AMI Aptio).

## Миссия

- Достичь уровня, при котором запрос «собери образ с патчем X» выполняется сборкой образа и предсказанием его поведения за максимум две проверочные итерации.
- Объём: вся структура образа, PSP-политики, разгоны и тайминги, включение вычислительных блоков GPU, разблокировка CPU (8C16T), функции новых BIOS, современная setup-оболочка.
- Ограничения: учёт будущих сценариев эксплуатации (Windows, античиты).

## Статус

- Фаза A (карта и механика PSP-политик) завершена: A1–A29.
- Патч-пакет D3-B2 собран и верифицирован статически; аппаратная проверка ожидает тестера.
- Донор-эталон (Cezanne мульти-BIOS) декодирован; его VCN-хвост скопирован в D3-B2 дословно.

## Ключевые результаты

- Замок VCN находится в PSP-политиках: гаскет (запись каталога 0x24) и TOS_SECURITY_POLICY (0x45) применяют пары «SMN-адрес → значение» через два интерпретатора в TOS-контейнере (0x28).
- Группа 0x210 — это mailbox-команды: 0x03E810 задаёт заголовок, 0x03E814 несёт командные слова; значение E810=6 у донора соответствует включению сегментов VCN.
- Интерпретатор fn@0xfeac зануляет значения всех групп кроме 0x280/0x281/0x282/0x284; интерпретатор fn@0x2178 применяет значения всех групп кроме 0x203/0x217.
- Семейство регистров xx234 (SMN 0x090xxxxx + 0x234) получает финальное значение 1 на стоке и на доноре; различие сторон — набор адресов: донор содержит 0x0900C234, сток его не содержит.
- Сторонний мод 8-ядерной разблокировки не затрагивает PSP-регион; замок ядер не гейтится PSP-политиками.
