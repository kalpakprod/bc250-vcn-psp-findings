# Группы политик: семантика, сток против донора

## Формат

- Группа = (тип u32, счётчик u32, счётчик × пары «адрес u32 → значение u32»).
- Адреса групп (0x201, 0x203, 0x280, 0x281) лежат в SMN-пространствах (0x03xxxxxx, 0x09xxxxxx); адреса группы 0x210 — короткие mailbox-адреса (0x03E810, 0x03E814).

## Состав сторон

- Сток-гаскет (0x24 @0x982000): (0x201: 1230, 0x203: 31, 0x210: 13, 0x280: 100, 0x281: 31).
- Сток-политика (0x45 @0x9CA400): (0x210: 13, 0x211: 0, 0x280: 100, 0x281: 31); содержимое групп совпадает с гаскетом.
- Донор-гаскет (Cezanne, 0x24 @0x25A000): (0x201: 916, 0x203: 32, 0x206: 45, 0x208: 0, 0x210: 4, 0x212: 28, 0x280: 367, 0x281: 28, 0x282: 3).
- Донор-политика (0x45 @0x2D7000): добавляет (0x211: 6, 0x213: 90, 0x214: 12, 0x215: 17, 0x217: 36, 0x218: 76, 0x225, 0x226, 0x227).

## Группа 0x210 — mailbox

- Пара 0x03E810 задаёт заголовок mailbox; пары 0x03E814 несут командные слова.
- Сток: E810 → 0; двенадцать команд E814, включая (0x2232C240, 0x2233C241, 0x2262C24E, 0x226EC250, 0x2278C261, 0x244FC441, 0x244EC442, 0x244DC443, 0x226CC24F, 0x2440C440, 0x2544C382, 0xF853C480).
- Донор: E810 → 6; одна команда E814 → 0x2544C382; плюс пары (0x1F8A4 → 0xB, 0x1F820 → 0x185103).
- Значение 6 заголовка донора соответствует включению сегментов VCN.

## Семейство xx234

- Семейство = SMN-регистры 0x090xxxxx со смещением 0x234; инстанс-регистры VCN.
- Обе стороны применяют два прохода: сначала значение 0, затем значение 1; финальное значение каждого адреса — 1.
- Различие сторон — набор адресов:
  - сток: 47 уникальных адресов;
  - донор: 59 уникальных адресов;
  - пересечение: 38; только сток: (0x9098234, 0x9099234, 0x909A234, 0x909B234, 0x909C234, 0x909D234, 0x90B6234, 0x90B7234, 0x90B8234); только донор: 21 адрес, включая 0x0900C234.
- Вывод: семантика значения единая (1 = включён); количество включённых инстансов различается.

## VCN-хвост донора

- Хвост группы 0x280 донора: (0x0900C234→0, 0x0900C914→0, 0x0900C930→0, 0x0900CB80→0, 0x0900C234→1).
- Финальные значения хвоста: C234 → 1, (C914, C930, CB80) → 0.
- Сток не содержит ни одного из этих четырёх адресов.
- Группа 0x201 донора содержит те же адреса с другими значениями: (C914 → 0x7FFF, C930 → 0x36, CB80 → 0xFF, C234 → 0 затем 1).

## DF-окно

- Регистр 0x0322011C: сток 0x87FF (ограниченное окно), донор 0x103FF/0x106FF/0x107FF (неограниченное).
- Сток несёт регистр в обеих группах (0x201, 0x280); донор — в 0x201.
