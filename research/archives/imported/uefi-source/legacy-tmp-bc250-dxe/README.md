# BC-250 Pre-OS VCN Unlock (EDK2 DXE / UEFI Probe)

## Скомпилированные артефакты (`tmp_bc250/dxe/bin/`)

- **`Bc250VcnProbeApp.efi` (12 288 байт)**:
  - Автономное диагностическое приложение UEFI Shell.
  - **Безопасный запуск без прошивки**: копируется на USB-накопитель (FAT32) в `/EFI/BOOT/` или запускается из UEFI Shell (`fs0:\Bc250VcnProbeApp.efi`).
  - Выполняет инициализацию SMU Q3, разблокировку тактовой сетки VCN (`0x23744`), включение питания Domain 6 (`0x23b14`) и конфигурацию 56 апертур Gasket Bank 12.
  - Опрашивает физический BAR5 MMIO (`UVD_VERSION` `0x20f24`, `UVD_POWER_STATUS` `0x1f810`) непосредственно в фазе UEFI.

- **`Bc250VcnUnlockDxe.efi` (4 608 байт)**:
  - DXE-драйвер для интеграции в том BIOS (через UEFITool / MMTool) после подтверждения работы через Shell.

## Инструкция по запуску проверки на плате `steammachine`

1. Скопировать `Bc250VcnProbeApp.efi` на загрузочную флешку FAT32.
2. Подключить клавиатуру/монитор (через DP-1) к BC-250.
3. При старте войти в **UEFI Shell** (через меню загрузки или тайм-аут).
4. Выполнить команду:
   ```shell
   fs0:
   Bc250VcnProbeApp.efi
   ```
5. Оценить вывод на экране:
   - Если `UVD_VERSION` возвращает `0x00002003` (или отличное от `0xFFFFFFFF`) — мост де-изолирован до запуска Linux!
   - Если возвращает `0xFFFFFFFF` — аппаратная изоляция (clamp) устанавливается на более ранней фазе PSP/ABL (Path 4).
