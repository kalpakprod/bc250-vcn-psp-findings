# Project scripts

Promote repeatable BC250 scripts here only after they have a defined input contract, safe output path, timeout, cleanup, provenance, and verification.

Imported source scripts are preserved under topic paths in `archives/imported/`; use `docs/import-catalog.md` and the per-file journals to locate them. Existing script families include APCB and gasket analysis, PSP policy parsing, UEFI/FV extraction, DXE build helpers, VCN probes, and artifact audits.
