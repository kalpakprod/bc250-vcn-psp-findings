Добавлена программная интеграция существующего recorder/watchdog. HOST_ALIVE пишет lost/recovered; до первого heartbeat состояние unknown. Потеря heartbeat сама по себе не вызывает reboot. Свой watchdog RP включается после startup и контролирует завершение проходов USB/recorder и доступных controller/network. До завершения startup watchdog не включён.

CDC: RECORDER_STATUS; RECORDER_READ 0, далее next_cursor из ответа.
HTTP (существующая Bearer-авторизация): GET /api/recorder; GET /api/recorder?cursor=0, затем next_cursor.
Чтение не очищает события. Ответ содержит до четырёх событий и oldest_sequence для обнаружения переполнения кольца. Типы: 1 heartbeat_lost, 2 heartbeat_recovered, 3 power_drop, 4 adapter_reboot, 5 watchdog_reset. Наличие типа power_drop не означает подключённый датчик. Unknown value=null.

Кольцо хранит 16 событий в RAM. Это не непрерывная запись напряжений и не долговременное сохранение инцидента через выключение RP. USB/сеть API на реальной плате не приняты. Нет выбранного/подключённого физического измерителя. Независимое питание/кабели не подтверждены.
